VOLEYINSIGHT 3.0.6 - CONFIGURACION COMPLETA DESDE EL PANEL

IMPORTANTE
No instales esta actualizacion mientras el sistema este abierto o durante un partido.

ARCHIVOS A REEMPLAZAR
1. dashboard/index.html
2. dashboard/js/sw.js
3. server-api.js
4. src/core/preparationStatus.js
5. tests/preparationStatus.test.mjs

INSTALACION
1. Cerra VoleyInsight y todas sus ventanas.
2. Descomprime el ZIP en Descargas.
3. Copia las carpetas y archivos incluidos sobre:
   C:\Users\User\Desktop\VoleyInsight
4. Acepta reemplazar los archivos existentes.
5. Ejecuta npm test.
6. Inicia el sistema con iniciar-partido.bat.

USO DEL PANEL
1. Escribi el Match ID.
2. Podes usar "Verificar en Metro" para comprobarlo y completar datos disponibles.
3. Completa equipo local, equipo visitante y categoria.
4. Presiona "Guardar y activar partido".
5. Confirma el resumen mostrado.

La verificacion de Metro es una ayuda, no un bloqueo. Si Metro todavia no publico
la planilla, el panel guarda el partido y el tracker continua intentando conectarse.
No es necesario editar data/config.json ni borrar partidos anteriores.

COMPROBACION ESPERADA
- El panel se recarga mostrando el nuevo Match ID y los equipos.
- El tracker informa el cambio de partido.
- Si Metro aun no habilito la planilla, se muestra como pendiente.
- Cuando Metro publica los datos, el tracker comienza a sincronizar automaticamente.
