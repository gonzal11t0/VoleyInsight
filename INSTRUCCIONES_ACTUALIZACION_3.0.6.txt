CAMBIOS PRINCIPALES

- Permite preparar un partido cuando la pagina publica de Metro ya existe pero
  la API de datos en vivo todavia no fue habilitada.
- Exige Match ID, nombres reales de ambos equipos y una categoria valida.
- Muestra una advertencia y pide confirmacion antes de guardar un ID pendiente.
- Conserva los datos de partidos anteriores.
- Reemplaza la categoria escrita a mano por una lista tomada del reglamento.
- El tracker comienza a sincronizar automaticamente cuando Metro publica datos.
- Elimina la dependencia googleapis, que estaba instalada pero no se utilizaba.
